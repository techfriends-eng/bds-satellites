# ADR 0002. Без typecheck: в репо сайта нет кода

- Статус: принято
- Дата: __DATE__

## Контекст

Чек-лист handbook (C19) требует `typecheck` и `lint` у проектов с `package.json`. Репо сайта —
тонкое (ADR 0001 bds-satellites): конфиг, дополнения к промптам, юниты. Кода на TS здесь нет, весь код —
в пакете bds-satellites, у которого свой полный гейт.

## Решение

`test:unit` — тесты конфига по маске `tests/**/*.test.mjs` (разбор, курсы, источники, модели), `lint` —
prettier. `typecheck` не заводится: проверять нечего, а пустая команда давала бы ложное «ok».

## Почему

- Фиктивный `typecheck` — отброшено: сторож, который ничего не проверяет, хуже его отсутствия (принцип 7).

## Последствия

audit.sh показывает C19 как FAIL; отклонение — этот ADR.
